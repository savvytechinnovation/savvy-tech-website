# Savvy Tech Website

Temporary "Coming Soon" site for [Savvy Tech Innovation](https://savvytechinnovation.com).

## Stack

- Next.js 15 (App Router, TypeScript)
- Tailwind CSS 3 with the Savvy brand palette
- Satoshi font via Fontshare

## Commands

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run start
```

## Structure

- `src/app/` - root layout, metadata and the single `/` route
- `src/components/ComingSoon.tsx` - the page itself
- `src/constants/site.ts` - contact email and social links
- `public/` - logo, favicon and Open Graph preview
